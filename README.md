# Som4lia V1 - Advanced Minecraft Auto-Clicker 🚀

**Som4lia V1** is a lightweight, high-performance, and fully customizable auto-clicker designed specifically for Minecraft players and general productivity. Built with C# and .NET, it offers a modern, intuitive user interface and advanced keybinding features.

---

## ✨ Key Features

* **Custom CPS Control:** Finely adjust your Clicks Per Second (CPS) to match your gameplay or task.
* **Advanced Keybinding:** Easily bind the start/stop trigger to extra mouse buttons (like **Mouse Button 5 / XButton2**) or any keyboard key.
* **Modern & Clean UI:** A distraction-free, stylish user interface designed for quick configuration.
* **Ultra-lightweight:** Minimal CPU and RAM footprint to ensure zero lag while gaming.

## ⚙️ How to Use

1.  Go to the [Releases](https://github.com/ImGoodBath/Som4lia_V1-Minecraft-Bedrock-Autoclick/releases) page and download the latest `Som4lia_V1.exe`.
2.  Run the executable (No installation required).
3.  Set your desired **CPS (Clicks Per Second)**.
4.  Select your activation key (e.g., Mouse 5 or a keyboard shortcut).
5.  Press the activation key to start/stop clicking!
